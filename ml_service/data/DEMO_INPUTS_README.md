# AgriSmart Demo Input Dataset

`demo_inputs.csv` contains a small set of manually prepared development examples for testing UI/API forms.

- It is **not** a training dataset.
- It is **not** field-validated agricultural data.
- Values are illustrative test inputs only.
- The existing model-training datasets remain the source for the development models.
- Replace these examples with validated local farm data before using the application for real agronomic decisions.
